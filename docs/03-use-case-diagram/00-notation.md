# 🔤 표기 관례

| 항목 | 값 |
|---|---|
| 대상 시스템 | 운전자 정산 시스템 (`driver-settlement-system`) |
| 상위 문서 | [요구사항 정의서](../02-requirements-specification/index.html) |
| 상태 | 초안 — 🚧 유스케이스는 **08.11(화) 중간 회의** 후 확정 |

---

Mermaid에는 UML 유스케이스 전용 문법이 없다. 아래 관례로 표현한다.

| UML 요소 | 이 문서의 표기 |
|---|---|
| 유스케이스 (타원) | 스타디움 노드 `([UC-01 …])` |
| Actor (막대 인간) | 사각형 노드 |
| 시스템 경계 | `subgraph` |
| 연관 (association) | 실선 화살표 |
| `<<include>>` | 점선 + `include` 레이블 |
| 🚧 미확정 유스케이스 | 회색 채움 + 이름에 🚧 |
