# 📖 용어 정의

| 용어 | 뜻 |
|---|---|
| **정산 (Settlement)** | 기사에게 지급할 금액을 기간 단위로 확정하는 일 |
| **대사 (Reconciliation)** | 두 출처의 숫자가 일치하는지 대조하는 일. 여기서는 원장 잔액 vs 정산 항목 합계 |
| **이중기입 (Double-Entry)** | 하나의 거래를 차변·대변 두 개의 분개로 동시에 기록하는 회계 방식. 합이 항상 0이 되어야 하므로 정합성 이상을 검출할 수 있다 |
| **분개 (Ledger Entry)** | 원장에 기록되는 개별 항목. 원장 서버 소유 개념 |
| **차변 (DEBIT) / 대변 (CREDIT)** | 이중기입의 양쪽. 결제 승인 시 플랫폼 예수금 증가(차변)와 기사 미지급금 증가(대변)가 함께 기록된다 |
| **미지급금** | 기사에게 줘야 하지만 아직 주지 않은 금액. 정산의 대상 |
| **멱등성 (Idempotency)** | 같은 요청을 여러 번 해도 결과가 한 번 한 것과 같은 성질 |
| **`targetDate`** | 정산 대상 일자. 정산 배치의 Job 파라미터이자 중복 실행 판정의 기준 키 |
| **청크 (Chunk)** | Spring Batch가 한 트랜잭션으로 묶어 처리하는 아이템 묶음 |
| **`RUNNING` / `CONFIRMED` / `PAID` / `FAILED`** | 정산 배치 상태. 각각 실행 중 / 금액 확정 / 지급 완료로 표시됨 / 실패 |
