§9전체 색인31행
⛔ 구현 전 막혀 있는 것
Q1 결제 응답에 driverId가 있는가(김주엽) — 없으면 기사별 집계 자체가 불가능하고, trips를 직접 읽는 건 CST-02 위반이다.
Q3 기사 계정의 accountId를 어떻게 얻는가(이치헌) — 없으면 대사를 구현할 수 없다.
두 질문은 제공자 레포에 contract 라벨 이슈로 올린다. 정산 레포에 쌓으면 정작 답할 사람이 보지 않는다.
